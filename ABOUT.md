# Anshul's REAPER Scripts

A collection of personal scripts for REAPER — built for my workflow as a guitarist learning and covering songs.

## What's Included

**ReaDashboard** — Modern project launcher built with ReaImGui. Browse, search, filter, and manage your REAPER projects with album art, custom tags, metadata, grid/list views, and keyboard navigation.

**Command Center GUI** — Floating toolbar for quick access to all scripts (9 core scripts + auto-discovered scripts). Includes ReaDashboard, tempo mapping, audio alignment, and stem import tools. Fully customizable and extensible.

**Workflow Scripts** — Tempo mapping (AI-powered beat detection from audio or click tracks), audio alignment via MFCC cross-correlation, tempo map import/export, video/audio stretching to match tempo, and Moises stem import with automatic track organization.

## Quick Start

1. In REAPER: `Extensions > ReaPack > Import repositories`
2. Paste: `https://raw.githubusercontent.com/AnshulJ999/REAPER-ReaScripts/main/index.xml`
3. Browse and install what you need

Or download manually and place scripts in your REAPER Scripts folder.

For full documentation, see the README files in the GitHub repository https://github.com/AnshulJ999/REAPER-ReaScripts.
